# Profile Avatars

Drop each profile's cute cartoon character image here with these EXACT filenames:

- prachi.png
- chanchal.png
- deepak.png
- guest.png

Recommended: square image (256x256 or bigger), PNG with transparent or solid
background. Until a file is added, the app shows a colorful gradient circle
with an emoji as a placeholder — so nothing looks broken in the meantime.

If you want to use .jpg/.webp instead of .png, update the `avatar` path for
that profile in `src/store/profileStore.js`.
